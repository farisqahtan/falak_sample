# عينة فلك
## المميزات
* **تصميم متجاوب:** واجهة مستخدم تتكيف بكفاءة مع جميع الأجهزة والشاشات بفضل الاعتماد على إطار عمل Bootstrap.
* **شريط تنقل علوي:** شريط تنقل ثابت يسهل الوصول السريع لأقسام الصفحة المختلفة (الرئيسية، خدماتنا، آراء العملاء، والتواصل).
* **قسم الخدمات:** يعرض الخدمات الرئيسية بوضوح
* **تأثيرات بصرية وحركية:** تم إضافة تأثيرات (Hover) لبطاقات الخدمات بحيث ترتفع للأعلى مع ظهور ظل عند التمرير عليها، بالإضافة إلى تفعيل التمرير السلس بين أقسام الصفحة.
* **نموذج تواصل:** واجهة مخصصة تتيح للعملاء إدخال تفاصيل مشاريعهم (الاسم، البريد الإلكتروني، وتفاصيل المشروع) لطلب استشارة فنية مجانية.
* **آراء العملاء:** قسم مخصص لعرض التقييمات الإيجابية للعملاء السابقين لتعزيز الثقة والموثوقية.

## التقنيات المستخدمة
* **HTML5:** لبناء الهيكل الأساسي للصفحة.
* **CSS3:** للتنسيقات المخصصة والرسوم المتحركة عبر ملف `style.css`.
* **Bootstrap:** مكتبة التصميم الأساسية (تم تضمين ملفات `bootstrap.css` و `bootstrap.js`) لتسريع التصميم وضمان التجاوب.
